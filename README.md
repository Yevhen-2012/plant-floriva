# Floriva / Plant

Статична версія `plant-f81e0d.webflow.io` для GitHub Pages. Збережено оригінальні стилі, відео, зображення, галереї та анімації. Каталог містить усі 8 товарів із даних Webflow API, 5 категорій і 5 опублікованих статей.

Опублікований сайт: https://yevhen-2012.github.io/plant-floriva/

Репозиторій: https://github.com/Yevhen-2012/plant-floriva

## Запуск

Потрібен Node.js 22 або новіший.

```sh
npm ci --ignore-scripts
npm run build
npm run check
npm start
```

Локальна адреса: `http://127.0.0.1:4175/`. Збірка створює `dist/`. Посилання відносні, тому сайт працює також у підкаталозі репозиторію GitHub Pages.

## Файли

- `snapshots/` — HTML опублікованих сторінок Webflow.
- `assets/` — локальні зображення, відео, шрифти, стилі та оригінальні скрипти.
- `content/collections.json` — дані товарів, варіантів і категорій для збірки.
- `public/` — локальний кошик і сумісність зі статичним хостингом.
- `data/capture.json` — відповідність адрес ресурсів локальним файлам.
- `scripts/` — збірка, перевірка, локальний сервер та інструменти імпорту.

Оригінальний ZIP розпаковано в локальну папку `source/`. Повний API-експорт 5 колекцій і 32 записів лежить у `data/collections/`; ці резервні файли та чернетки виключені з Git. Сайт публікує лише необхідні дані каталогу та опубліковані статті.

## Можливості

Кошик зберігається в цьому браузері, підтримує додавання, зміну кількості, видалення та підрахунок суми в EUR. Онлайн-оплата та надсилання замовлень не підключені. Форма підписки показує чесне повідомлення, поки не підключено сервіс розсилок.

Botanical Card закріплена в правому нижньому куті екрана на всіх основних сторінках. Кнопка збільшується при наведенні та відкриває інтерфейс майбутнього чату. Поки бот не підключений, поле повідомлення неактивне; посилання на каталог і статті працюють. Віджет не надсилає повідомлень, не підключається до API та не зберігає розмови. Його розмітка — у `templates/assistant.html`, стилі й поведінка відкриття — у `public/assistant.css` та `public/assistant.js`.

Дані є знімком стану Webflow від 22 жовтня 2026 року. Зміни у Webflow автоматично не синхронізуються. Оновлення каталогу вносяться у `content/collections.json`, верстки та статей — у `snapshots/`, після чого запускається збірка.

Live Demo завантажує відео лише після натискання, використовує один підтримуваний формат і ставить відтворення на паузу при закритті. Зображення мають адаптивні WebP-варіанти та розміри `sizes` відповідно до верстки; оригінальні файли збережені. Після додавання або заміни зображень запустіть `python scripts/optimize-images.py` (потрібен Pillow), потім звичайну Node-збірку. Згенеровані `assets/responsive/` і `content/responsive-images.json` зберігаються в Git, тому GitHub Actions не потребує Pillow.

Для нового API-експорту `npm run import:webflow` відкриває локальну форму. Токен надсилається лише до `api.webflow.com` і не зберігається у файлах. На Windows із HTTPS-фільтрацією використовуйте Node.js 24 з `--use-system-ca` або стандартний HTTPS-клієнт Windows. Не вимикайте перевірку сертифікатів.

## Публікація

У налаштуваннях GitHub Pages вибрано GitHub Actions. Workflow перевіряє та публікує `dist/` після змін у `main`. Для збірки та роботи сайту Webflow API token не потрібний.
